# Recruiter Visibility - do this once, agent maintains it

Target: appear in recruiter search + "Open to Work" feed.

## 1. Keywords (agent's `target_keywords`)
Put these EXACT strings in Headline + About + Skills:
`python, fastapi, postgres, llm agents, open to work, remote`
Recruiters literally Ctrl+F these.

## 2. Headline formula
`Role | Stack (3 max) | Proof | Open to X`
Ex: `Python Backend Dev | FastAPI, Postgres, LLM Agents | Built 3 AI tools | Open to Remote`

## 3. About (first 3 lines matter - rest is "see more")
Line1: who you help. Line2: proof with numbers. Line3: contact.
Ex: `I build backend + AI agents for startups. 3 tools shipped, 5k+ post views. Email: you@mail.com`

## 4. Featured + Activity
- Pin best-view post (agent `analytics` tells which)
- Add resume PDF + Github + top project
- Comment 5x/day on hiring managers (2 real lines, not "Interested")

## 5. Open To Work settings
Profile -> Open to -> Finding a new job -> titles from `target_roles`,
locations Remote + your city, visibility = Recruiters only (keeps feed clean).

## 6. What agent tracks weekly
Views/post, profile views after commenting, recruiter DMs count.
If views <500 after 3 posts: change hook (first line). If no recruiter DM in 2 weeks: rewrite headline.
