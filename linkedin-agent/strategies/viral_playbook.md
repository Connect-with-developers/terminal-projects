# Viral Playbook (without cringe)

LinkedIn rewards: dwell time + early comments + reposts.

1. **Hook (line 1, <60 chars, no emoji):** number or contrarian
   - good: "I sent 50 DMs. 0 replies. Then 10. 6 replies."
   - bad: "🚀🚀 Thrilled to announce..."

2. **Format:** 1 story, blank lines, 3 bullets max, 1 question end.
   Under 150 words. Mobile readers quit after 8 lines.

3. **Post timing IST:** Tue-Thu 9am or 6:30pm. 1/day max. 2-3/week ideal.

4. **First 60 min:** reply to EVERY comment with a question.
   This doubles thread views. Agent drafts replies, you approve.

5. **Repeat winners:** agent `analytics` shows ER% = (likes+3*comments+5*reposts)/views.
   ER >5% = repeat format. ER <1% = change hook only, keep topic.

6. **Never:** pods ("like for like"), mass tag 20 people, external link in post
   (put link in first comment - algo penalizes outbound links).
